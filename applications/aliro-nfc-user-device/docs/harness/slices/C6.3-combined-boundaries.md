## Objective

Verify application boundaries when the corrected stack drives combined and
boundary Step-Up cases.

## Application-owned scope

- Supply Access and Revocation snapshots for combined, partial-match,
  no-match, maximum-size, chained, and one-byte-over-limit cases.
- Verify application bounds, snapshot lifetime, response-buffer lifetime,
  transaction notification, and cleanup.

## Non-goals and stack boundary

Document selection, deterministic CBOR, output ordering, chaining, response
capacity decisions, and failure sequencing are stack-owned.

## Required verification

Run the combined/boundary host matrix through the real stack.

## Exit criteria

All P2 application responsibilities are represented without duplicating
stack behavior.
