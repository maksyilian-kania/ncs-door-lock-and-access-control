## Objective

Prove the application persistent-key recovery model at every failure
boundary.

## Application-owned scope

- Inject failure before and after every metadata and PSA transition.
- Verify preservation of prior committed state or deterministic recovery.
- Verify recovery idempotence and PSA-object leak freedom.
- Record the fault matrix as durable evidence.

## Non-goals and stack boundary

Do not inject into or change stack key derivation/protocol sequencing.

## Required verification

Run the complete backend fault matrix on the host. Target reset/power-loss
qualification remains C7.1.

## Exit criteria

Every transition and recovery outcome is covered and the durable fault
matrix contains no unexplained state.
