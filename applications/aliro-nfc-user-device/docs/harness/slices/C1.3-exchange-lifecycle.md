## Objective

Verify mailbox and lifecycle application behavior when the real stack drives
EXCHANGE, CONTROL FLOW, teardown, and recovery.

## Application-owned scope

- Exercise the application mailbox backend through stack-driven EXCHANGE.
- Verify mailbox atomicity, lifecycle cleanup, field-loss handling, and
  recovery.
- Verify transaction notification and application resource release.

## Non-goals and stack boundary

Do not parse EXCHANGE, construct secure-channel responses, select status
words, or implement Aliro failure sequencing.

## Required verification

Run positive, failure, field-loss, and recovery host integration cases.

## Exit criteria

Application EXCHANGE/lifecycle integration passes or exact stack blockers
are recorded.
