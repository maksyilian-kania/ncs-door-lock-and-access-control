## Objective

Verify generic application PSA and `PersistentKey` operations exercised by
the stack's Fast flow.

## Application-owned scope

- Test opaque import, derivation-input handle use, lookup, copy, and
  destruction operations exposed by the current public contract.
- Verify failure outputs and resource ownership.

## Non-goals and stack boundary

Do not construct Fast salts, KDF inputs, cryptograms, direction keys,
counters, or Fast protocol state.

## Required verification

Run direct generic crypto and persistent-key backend tests.

## Exit criteria

Every application backend operation required by the current Fast contract is
directly covered.
