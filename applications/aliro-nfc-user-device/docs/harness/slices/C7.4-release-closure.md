## Objective

Close application security, traceability, and release evidence without
overclaiming stack or external certification status.

## Application-owned scope

- Audit logs, CLI output, diagnostics, and artifacts for sensitive material.
- Finalize P1/P2 traceability with exact application/stack revisions,
  commands, artifacts, target results, and external dependencies.
- Confirm every selected requirement has a truthful final status.

## Non-goals and stack boundary

Do not mark a stack-owned or externally certified behavior accepted without
the corresponding evidence.

## Required verification

Run traceability validation, secret/log inspection, final application host
suite, DK build, and applicable release checks.

## Exit criteria

Every selected requirement is accepted or has a narrowly stated application,
stack, hardware, or external certification dependency.
