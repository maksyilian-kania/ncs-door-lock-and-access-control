## Objective

Close application security, traceability, and release evidence without
overclaiming stack or external certification status.

## Application-owned scope

- Audit logs, CLI output, diagnostics, and artifacts for sensitive material.
- Finalize P1/P2 traceability with exact application/stack revisions,
  commands, artifacts, target results, and external dependencies.
- Confirm every selected requirement has a truthful final status.

## Non-goals and stack boundary

Do not mark a stack-owned or externally certified behavior accepted without
the corresponding evidence.

## Required verification

Run traceability validation, secret/log inspection, final application host
suite, DK build, and applicable release checks.

## Acceptance matrix

- Re-run the complete host matrix and clean release-like DK build; record
  configurations, cases, warnings, revisions, and commands.
- Validate traceability: every selected requirement appears exactly once,
  references only completed slices/existing evidence, and has no `planned`
  status.
- A `verified-host` row identifies its remaining target dependency;
  `verified-target` has target evidence; `blocked-stack` names an exact
  revision and reproducible finding.
- Reconcile every applicable external User Device test ID from
  Requirements.pdf §12 with C7.2/C7.3 evidence and selected PICS.
- Provision unique sentinel secrets and search release binaries/artifacts,
  CLI output, logs, diagnostics, crash output, and captured runtime output
  for their exact bytes. Separately inspect production source for raw-key
  export/log paths; documented test-vector fixtures are not treated as leaks.
- Publish an application-complete result only if no selected
  application-owned requirement remains open; state explicitly when a stack,
  hardware, or external blocker prevents complete-system compliance.

## Exit criteria

Traceability contains no unexplained/planned row, all release checks pass,
and the final claim precisely separates application completion from any
remaining stack, hardware, or external dependency.
