## Objective

Establish a clean application baseline against the checked-out User Device
stack and map the complete public application contract.

## Application-owned scope

- Build the application without System OFF.
- Record the exact application and `ncs-aliro` revisions and selected PICS.
- Map every `Aliro::Interface::UserDevice` declaration to its application
  definition.
- Identify missing or stale application adapters.

## Deliverables

- Clean DK build.
- Public-contract mapping separating application gaps from stack blockers.

## Non-goals and stack boundary

Do not implement protocol behavior to satisfy a missing stack capability or
modify `ncs-aliro`.

## Required verification

- DK application build.
- Link/symbol inspection for every public User Device interface.

## Exit criteria

The application builds and every public declaration is mapped to an
implementation, an application gap, or an exact stack blocker.
