## Objective

Make application `Kpersistent` replacement and deletion recoverable across
settings/NVS and persistent PSA storage.

## Application-owned scope

- Define a durable transaction/recovery model.
- Recover interrupted replacement and deletion at boot.
- Destroy orphaned staged or retired persistent keys.
- Propagate cleanup failures rather than leaving metadata/key divergence.

## Non-goals and stack boundary

Do not alter the stack's key derivation, lookup key, or protocol commit
timing.

## Required verification

Test every recovery state directly with fake persistence and PSA ownership,
including repeated boot recovery.

## Exit criteria

Every persistence transition has a deterministic, idempotent recovery rule
with no unowned PSA object.
