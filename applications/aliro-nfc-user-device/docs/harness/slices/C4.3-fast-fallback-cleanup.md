## Objective

Verify application state and resource ownership across Fast match, miss,
fallback, repetition, and teardown.

## Application-owned scope

- Exercise matching and missing persistent state, Standard fallback,
  repeated sessions, field loss, and teardown through the real stack.
- Assert application-observable persistent state and opaque-handle cleanup.

## Non-goals and stack boundary

Cover-cryptogram generation/content, fallback decisions, and wire-visible
privacy behavior are stack-owned. Record discrepancies; do not implement
them in the application.

## Required verification

Run host integration cases with backend resource/leak accounting.

## Exit criteria

No application resource leak or stale state remains; protocol discrepancies
are precise stack blockers.
