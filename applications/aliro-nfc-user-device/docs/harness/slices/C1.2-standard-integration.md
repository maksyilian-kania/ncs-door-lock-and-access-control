## Objective

Verify the application backends used by certificate and no-certificate
Expedited Standard flows through the real stack.

## Application-owned scope

- Verify transport delivery, credential/trust lookup, authorization,
  signing, generic crypto adapter calls, and transaction notification.
- Add application integration coverage needed to expose those boundaries.

## Non-goals and stack boundary

APDU contents, chaining decisions, authentication orchestration, KDF inputs,
status words, and failure sequencing are stack-owned and must not be
implemented here.

## Required verification

Run certificate and no-certificate host integration cases through
`UserDeviceStack`.

## Exit criteria

Application-owned integration passes or each failure is recorded as an
exact external stack blocker.
