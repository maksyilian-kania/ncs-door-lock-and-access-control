## Objective

Audit a stack revision that claims complete Revocation/combined Step-Up and
failure closeout before application integration continues.

## Entry gate

Do not start until the stack reports Revocation-only and combined responses,
truthful signaling, complete failure cleanup, and fixes for known
deterministic-CBOR/ordering defects.

## Application-owned scope

- Record and inspect the corrected stack revision/public headers.
- Adapt only for genuine public-contract changes.
- Re-run affected C1-C5 application regression tests.

## Non-goals and stack boundary

Do not fix stack implementation defects or add compatibility workarounds.

## Required verification

Contract diff, application build, and affected host suites.

## Exit criteria

The updated stack is usable through its public API without application
protocol workarounds.
