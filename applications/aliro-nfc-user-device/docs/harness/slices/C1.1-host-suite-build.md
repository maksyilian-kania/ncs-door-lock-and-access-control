## Objective

Restore a reliable host-test baseline against the current public stack
contract.

## Application-owned scope

- Make every existing Aliro User Device application host configuration
  compile and link.
- Update application test wiring, fakes, adapters, and application-owned
  implementations where the public contract changed.
- Categorize runtime failures without broadening this slice into behavior
  fixes.

## Deliverables

- Buildable host-test matrix.
- Precise list of remaining runtime failures by application or stack owner.

## Non-goals and stack boundary

Do not change stack protocol behavior or weaken tests to fit current output.

## Required verification

Run the complete application host-test tree through compilation/linking and
record the configuration and case totals.

## Exit criteria

Every host configuration builds; runtime failures are reproducible and
correctly owned.
