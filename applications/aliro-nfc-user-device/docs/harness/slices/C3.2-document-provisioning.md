## Objective

Make application document provisioning deterministic and failure-atomic.

## Application-owned scope

- Reject malformed application provisioning encoding, inconsistent
  metadata, and oversized input.
- Preserve previously committed documents on every rejected input/failure.
- Cover create, update, clear, delete, and reset paths through the
  development provisioning surface.

## Non-goals and stack boundary

Do not validate stack-owned DeviceRequest/DeviceResponse CBOR or reconstruct
Step-Up responses.

## Required verification

Run provisioning boundary and failure tests on host. Target persistence
remains C7.1.

## Exit criteria

Every provisioning result is deterministic and failures leave committed
state unchanged.
