## Objective

Verify application mailbox behavior when the real stack drives EXCHANGE over
a Fast session.

## Application-owned scope

- Exercise reads, writes, sets, permissions, commit, rollback, and lifecycle
  serialization through the existing mailbox backend.
- Verify snapshots and committed state at the application boundary.

## Non-goals and stack boundary

Do not parse EXCHANGE, orchestrate the secure channel, select counters, or
construct success/failure responses.

## Required verification

Run positive and failed Fast EXCHANGE host integration cases.

## Exit criteria

Application mailbox behavior passes without application-side protocol
processing.
