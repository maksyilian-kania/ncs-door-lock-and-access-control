## Objective

Establish current, non-overclaimed Phase 1 application traceability.

## Application-owned scope

- Reconcile every P1 requirement with current host evidence.
- Create `../traceability.yaml` using the harness traceability policy.
- Assign target-only and external-harness checks to C7.
- Identify exact stack blockers separately from application status.

## Deliverables

- Machine-readable P1 traceability baseline.
- Durable evidence only where the audit produces a material decision or
  blocker.

## Non-goals and stack boundary

Do not convert absent target evidence or stack behavior into application
implementation work.

## Required verification

Run the traceability validator and confirm every P1 identifier appears
exactly once.

## Exit criteria

Every P1 row has current host evidence, a C7 target assignment, or a precise
external blocker without claiming complete-system compliance.
