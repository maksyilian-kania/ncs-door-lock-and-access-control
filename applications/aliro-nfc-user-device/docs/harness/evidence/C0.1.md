## Application gaps

These are application-owned. None is fixed in C0.1.

1. `Credential::Reset()` does not satisfy its full contract. The header
   says it factory-resets mailbox data as well. The adapter only calls
   `AliroUd::Credential::Store::Reset()`, which cascades to documents
   (stored in the credential record) and `Kpersistent`
   (`PersistentKey::Store::DeleteAllForCredential`). Mailbox bytes are
   erased only by the CLI (`cli.cpp` `CmdCredentialReset` →
   `Mailbox::Store::EraseAll()`), and only after the whole reset succeeds.
   Likewise, `Credential::Delete()` leaves mailbox erasure to the CLI.
   The `DeleteAllForCredential` result is also discarded.
   Owners: C2.x (`Kpersistent`), C3.x (documents), C1.3 (lifecycle).
2. `Transaction::NotifyResult()` is stale. `transaction.cpp` still calls
   itself a placeholder and says no path reports `Success`, but stack
   `session.cpp:60` now latches `TransactionOutcome::Success`. The only
   behavior is logging. Owner: C1.3.
3. The standalone `Document::Delete/Reset` and `PersistentKey::Delete/Reset`
   adapters have no caller in either the stack or the application. Their
   behavior is reached only through the credential-store cascade. Owners:
   C2.1 and C3.1 must test them directly or document them as unused.
4. `Nfc::GetTimingConstraints()` returns `{0}` and
   `Os::GetTrustedTimestamp()` returns `std::nullopt`. Both are
   deliberate AWP7/AWP1 decisions, and the stack doesn't call either at
   this revision. They are re-checked at C6.1.

## Stack observations

- No link-level contract blocker exists at `99ed739a`.
- Public doc drift: `types.h:179` still documents
  `TransactionOutcome::Success` as "Reserved ... no WP5.5 path produces
  this value", while `stack/src/user_device/session.cpp:60` produces it.
  This is not a blocker; the application must handle all three outcomes.
- The Step-Up gate in the harness `README.md` ("Current stack gate") is
  unchanged. It concerns stack-internal behavior rather than a missing
  public declaration, and C6.1 audits it.
