# Phase 1 archive

This directory contains the frozen planning, traceability, and evidence
artifacts from the Aliro NFC User Device Phase 1 AWP campaign.

The files are historical records. Do not update them for current compliance
work.

Archived contents:

- `APP_PLAN.md` — historical AWP0-AWP8 implementation plan.
- `traceability-p1.md` — Phase 1 requirement status and evidence mapping.
- `evidence/` — per-AWP command and verification records.
- `wp7_stack_impact.md` and `stack_update_wp7fix.md` — historical stack
compatibility and re-verification records.
